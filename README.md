# KOPEYKA Launcher 0.2.0-beta

Пиксельный Minecraft Java лаунчер для Windows. Версия 0.2 beta собирает управление версиями, загрузчиками и контентом в одну рабочую оболочку.

## Что умеет

- Minecraft Java: Vanilla, Fabric, Forge, NeoForge, OptiFine и Forge + OptiFine.
- Изолированные сборки модов по связке «версия + загрузчик».
- Копирование набора модов между сборками без удаления исходной.
- Вкладки установленных модов, модов из каталога, ресурспаков и шейдеров.
- Поиск и установка контента из Modrinth с проверкой совместимости и зависимостей.
- До 15 локальных профилей с никами и аватарами.
- Общие миры, перенос настроек Minecraft и счётчик времени игры.
- Кэш каталогов, проверка SHA-256 загрузок и восстановление после сетевых ошибок.
- Компактная отдельная заставка запуска с ограниченным таймаутом.
- Журнал запуска и сообщения об ошибках интерфейса.

## Скачать

Открой [релиз 0.2.0-beta](https://github.com/Arab228d/kopeyka-launcher/releases/tag/v0.2.0-beta). Установщик Windows публикуется отдельно после сборки пакета.

## Запуск из исходников

Требуется Node.js 20+ и Windows:

```powershell
npm ci
npm start
```

Проверки:

```powershell
npm test
npm run test:ui
```

Сборка установщика:

```powershell
npm run build:installer
```

Результат появится в `dist/`. Java runtime-файлы берутся из `build/`; игровые файлы Minecraft в репозиторий не входят.

## Где хранятся данные

По умолчанию данные находятся в `%USERPROFILE%\\.kopeyka\\launcher`, а игровые файлы — в `%USERPROFILE%\\.kopeyka\\minecraft`. Папку игры можно изменить в настройках.

Моды хранятся отдельно для каждой сборки:

```text
.minecraft/profiles/1.21.1-fabric/mods/
.minecraft/profiles/1.21.1-forge/mods/
```

## Ограничения beta

Лаунчер использует локальные профили без Microsoft-входа. Для серверов с официальной авторизацией потребуется отдельная реализация входа. EXE пока не подписан. Проект не связан с Mojang или Microsoft.

## Структура

- `src/main.js` — окно Electron, IPC и запуск игры.
- `src/installer.js` — загрузка и проверка файлов.
- `src/loaders.js` — Forge, Fabric, NeoForge и OptiFine.
- `src/mods.js`, `src/shaders.js` — контент и профили сборок.
- `src/ui/` — интерфейс лаунчера.
- `test/` — автоматические проверки.
