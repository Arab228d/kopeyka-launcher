# KOPEYKA Launcher 0.1.1 Beta

- Редактор профилей теперь в стиле главного экрана: пиксельные рамки, карточки с аватарами, золотое выделение активного игрока и зелёная кнопка добавления.
- После обновления появляется «Что нового» с изменениями установленной версии. Его можно снова открыть в настройках.
- Логотип экрана загрузки используется как значок приложения, установщика и ярлыков.

Скачайте KOPEYKA-Laucher-Setup-0.1.1-beta.exe. Установщик для Windows x64 включает Electron и Java, создаёт ярлыки и сохраняет настройки и игровые данные.

Это предварительный выпуск. После перехода с 0.1 Beta последующие изменения можно просматривать в окне «Что нового».
