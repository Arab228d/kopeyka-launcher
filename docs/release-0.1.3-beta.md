# KOPEYKA Launcher 0.1.3 Beta

Обновление оформления интерфейса.

- Тёмно-зелёная кнопка «Играть» с яркой подсветкой при наведении.
- Логотип вместо текстовой надписи в верхней панели.
- Обновлённые состояния кнопок управления окном.
- Окно «Что нового» с пиксельными рамками в стиле лаунчера.
- Иконка приложения в окне запуска.

Windows x64. Скачайте KOPEYKA-Launcher-Setup-0.1.3-beta.exe или обновитесь из лаунчера. Настройки, профили и игровые данные хранятся отдельно от приложения.
