# KOPEYKA Laucher 0.2.2 Beta

- Новый логотип с травяным блоком на стартовом экране и в выборе версии Minecraft.
- При первом запуске обновления выбирается последняя стабильная версия из каталога Mojang. Последующий ручной выбор версии и загрузчика сохраняется.
- Последняя стабильная версия расположена первой в списке.
- Новые пиксельные рамки кнопок с состояниями наведения, выбора и блокировки.
- Кнопки журнала и папки игры размещены рядом над профилем.

Скачайте **KOPEYKA-Laucher-Setup-0.2.2-beta.exe** и запустите. Установка в один шаг создаёт ярлыки на рабочем столе и в меню «Пуск». Включены Electron и Java 8, 16, 17, 21 и 25. Игровые данные и настройки сохраняются при обновлении. Для скачивания Minecraft нужен интернет.

Windows x64. Предварительный выпуск. Контрольная сумма установщика опубликована в SHA256SUMS.txt.

Проверены 24 автоматических теста и сценарии интерфейса, включая выбор последней стабильной версии вместо старого значения по умолчанию и сохранение ручного выбора.
