# Проверка 0.1.5 Beta

- Windows x64, Electron 44.9.3.
- 70 автоматических тестов: установка, контрольные суммы, кеши, профили, каталоги, зависимости модов, шейдеры, ресурспаки и связка Forge + OptiFine.
- Проверка интерфейса: обычный и минимальный размер окна, каталог внутри панели, одинаковая высота карточек, смена версии во время запроса, восстановление после ошибки загрузки настроек.
- Проверка жизненного цикла: повторный запуск, возврат окна после выхода, сбоя и ошибки подготовки; сериализация сохранений и сохранение времени игры при закрытии.
- Реальный Minecraft 1.21.1 с Forge 52.0.16 и OptiFine HD U J1: загрузка OptiFine подтверждена журналом, клиент достиг инициализации графики и звука. Тест использовал отдельную папку, миры не открывались.
- Нагрузочный сценарий интерфейса: 180 движений указателя и 2000 скрытых записей журнала; в покое нет пересчётов стилей и раскладки. Замер использует программный рендеринг и не является гарантией FPS на другом компьютере.
- Архив приложения проверен: версия 0.1.5-beta, новые модули включены; тесты, артефакты, исходники Java и удалённые ассеты не попадают в установщик.
- После обновления зависимостей npm audit не сообщает о high/critical. Остаются четыре moderate-предупреждения в старой цепочке minecraft-launcher-core/request/tough-cookie/uuid, для которых npm не предлагает исправления. Полная замена движка не входит в этот выпуск.

Проверка не охватывает все версии Minecraft и все сочетания сторонних модов. EXE не подписан.

- Установщик NSIS 0.1.5-beta проверен командой 7-Zip test: Everything is Ok. Упакованный лаунчер запущен, главное окно отвечает.
