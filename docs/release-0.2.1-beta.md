# KOPEYKA Laucher 0.2.1 Beta

- Новый стартовый экран: логотип по центру с мягкой пульсацией.
- Окно появляется до подготовки основного интерфейса. После загрузки локальных ресурсов меню плавно раскрывается; ожидание списка версий не задерживает открытие меню.
- Убрана плитка с боковой панели, оставлено размытие движущегося фона.
- Исправлены обводки кнопок и полей: ровные скруглённые края.

Скачайте **KOPEYKA-Laucher-Setup-0.2.1-beta.exe** и запустите. Установка в один шаг создаёт ярлыки на рабочем столе и в меню «Пуск». Включены Electron и Java 8, 16, 17, 21 и 25. Игровые данные и настройки сохраняются при обновлении. Для скачивания Minecraft нужен интернет.

Windows x64. Предварительный выпуск. Контрольная сумма установщика опубликована в SHA256SUMS.txt.

Проверены 23 автоматических теста и сценарии интерфейса, включая стартовый экран при задержке загрузки настроек и последующее появление меню.
