# KOPEYKA Launcher 0.1 Beta

Обновлённый выпуск лаунчера Minecraft Java для Windows x64.

- Пиксельные кнопки со свечением, живой фон и прозрачные панели с плавными переходами.
- Новый журнал запуска: компактное окно, читаемые записи, сохранение файла.
- Автоматическая установка Fabric, Forge, NeoForge и OptiFine для доступных версий.
- Локальные моды из JAR и каталог шейдеров с изображениями.
- Постоянная папка данных, общие миры, перенос настроек и системный язык при первом запуске Minecraft.
- Возврат лаунчера после выхода из игры и счётчик времени игры.
- Проверка актуальных версий и обновление лаунчера через GitHub.

Скачайте KOPEYKA-Laucher-Setup-0.1.0-beta.exe. Включены Electron и Java; установщик создаёт ярлыки. Для загрузки Minecraft требуется интернет.

Нумерация начинается заново с 0.1 Beta. Переход с 0.2.x/0.3.0 выполняется вручную, поскольку автоматическое обновление не предлагает меньший номер. Настройки и игровые данные сохраняются.

Локальные профили работают без Microsoft-входа. Шейдеры требуют совместимого графического мода. Доступность загрузчиков зависит от версии Minecraft. Это предварительный выпуск.
