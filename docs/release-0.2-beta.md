# KOPEYKA Laucher 0.2 Beta

## Установка

Скачайте **KOPEYKA-Laucher-Setup-0.2.0-beta.exe** и запустите его. Установка выполняется для текущего пользователя в один шаг; создаются ярлыки на рабочем столе и в меню «Пуск».

Включены Electron и Java 8, 16, 17, 21 и 25. Node.js и Java отдельно устанавливать не нужно. Для скачивания Minecraft, Fabric и Forge нужен интернет. OptiFine выбирается локальным JAR-файлом. Поддерживается Windows x64.

## Новое

- Обновлённый интерфейс: движущийся фон, синхронное размытие, почти незаметная пиксельная прозрачность и плавные анимации.
- До 15 локальных профилей с разными никами; редактор открывается нажатием на карточку игрока.
- «Настройки», «Играть» и «Mods» внизу главного экрана. Версия и загрузчик выбираются одним списком под «Играть».
- Экран «Загрузка игры» с приближением и обесцвечиванием фона; скрытие лаунчера после сигнала готовности Minecraft.
- Оптимизированы обновления прогресса, журнала и движения фона.

Это предварительная Beta-версия. Профили локальные, без Microsoft-авторизации. При обновлении игровые файлы и настройки сохраняются.

Архивы встроенной Java проверены по SHA-256. Рядом с установщиком опубликован файл SHA256SUMS.txt для проверки загрузки.
