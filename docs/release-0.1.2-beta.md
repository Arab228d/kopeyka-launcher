# KOPEYKA Launcher 0.1.2 Beta

Обновление производительности и удобства.

- Сохранённые каталоги Minecraft и загрузчиков открываются сразу. Проверка новых версий продолжается в фоне; при первой установке нужен ответ сервера.
- Одновременные запросы обновления одного каталога используют одну сетевую операцию.
- Движение мыши за открытыми диалогами больше не запускает обновление параллакса.
- Оптимизирована обработка времени сообщений журнала.
- Журнал не перескакивает вниз при новых сообщениях, если пользователь читает старые записи.

Windows x64. Скачайте KOPEYKA-Launcher-Setup-0.1.2-beta.exe или нажмите обновление в лаунчере. Настройки и игровые данные хранятся отдельно от приложения.

Проверки: 40 автоматических тестов, проверка интерфейса и локальный сценарий нагрузки. Это предварительный выпуск; ускорение зависит от сети и компьютера.
